# kde-plasma

Symlinked files (`home/`) plus `post-install.sh`. The script writes settings with `kwriteconfig6`, because KDE rewrites its rc files, which would break a symlink.

## Settings (post-install.sh)
| Setting | Why |
|---|---|
| Power, AC only: never auto-suspend; dim at 5 min; screens off at 30 min; no lock when screens go off | Desktop runs long jobs. Screen-off was 10 min, raised to 30 min. |
| Screen locker: `Autolock=false`, `LockOnResume=true` | No idle lock, but lock after sleep. LockOnResume was off on 11-17, back on 11-19. |
| Night Light 3400 K, 18:00 to 07:00 | Replaces f.lux. Activating needed a false→true toggle. |
| KWin `screenedgeEnabled=false` | Removes the blue screen-edge glow. |
| Window rule `^steam_app_\d+$`: fullscreen, no decoration | Steam games open borderless fullscreen. The user reported lag with it on, so watch for that. |
| Dolphin global view props with hidden files shown | Always show dotfiles. |
| No popup for `remotedesktopstarted` | yada's paste triggers it. |
| WirePlumber `bluetooth.autoswitch-to-headset-profile false` | AirPods sound bad in headset mode. |
| Images open in XnView MP | Replaces the Windows image viewer. |

## Files (home/)
- `kwin/scripts/no-attention`: clears "demands attention" on every window, so the taskbar never flashes. Browser windows get raised and focused instead.
- `kwin/scripts/activity-first-desktop`: switching to the **Scratch** activity goes to desktop 1. The activity ID is hard-coded in `main.js`. On a new machine, create the activity and put its ID there (`post-install.sh` warns when it's missing).
- `plasma/desktoptheme/glass-dock`: Plasma style with a translucent rounded dock. The panel SVG was generated by Python (R=20, fill 0.38, edge 0.22); blur on, contrast off; `icons/media.svg` has play and pause swapped.
- `icons/breeze{,-dark}/status/*/media-playback-{playing,paused}.svg`: swapped, so the tray shows Pause while media plays. The `-symbolic` links and the `@2x`/`@3x` links are needed at 125% scale.

## Manual (per machine, not scripted)
- **Scratch activity**: AddActivity over D-Bus, made off-the-record (`kactivitymanagerd-pluginsrc`).
- **Virtual desktops**: 2, named Work and Personal.
- **Shortcuts**: Overview on Meta+W and Meta+Tab; Alt+Tab only for Walk Through Windows; Sleep on the `Sleep` key and Meta+X, U, S (**untested**); yada toggle-recording on Ctrl+Shift+;.
- **Dock**: bottom, floating, fit-width, centered, height 56, autohide, `panelOpacity=2`, one per screen. Pins: System Settings, Discover, file manager, Firefox, Chrome, VS Code, Spotify. Task manager `unhideOnAttention=false`. Tray hides veracrypt and xdg-desktop-portal-kde. Panel IDs differ per machine, so set these in the UI.
- **Displays**: 2× ASUS VG32V at 125%. Insignia TV on HDMI-A-2 at 3840x2160@60, scale 2: `kscreen-doctor output.HDMI-A-2.mode.3840x2160@60 output.HDMI-A-2.scale.2`. The TV also needs HDMI Input Mode 2.0 in its own menu. TV audio: `pactl set-card-profile alsa_card.pci-0000_01_00.1 output:hdmi-stereo`.
- **Default browser**: `MySetups/SetDefaultBrowser.kde.py --install`. **RK S70 keyboard**: `MySetups/RoyalKludgeRKS70.kde.sh`.
